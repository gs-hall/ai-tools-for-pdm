# «Кто выгуливает Бориса»

Учебный Node.js micro-MVP для вымышленной компании «Догяндекс». Общая страница, на которой сотрудники записываются на прогулку с псом Борисом и видят, кто кормил его последним.

Требования к продукту — в `spec.md`, правила работы с ИИ-агентом — в `AGENTS.md`, этапы и проверки — в `PLAN.md`. Этот файл описывает только фактическое состояние проекта.

## Статус

Приложение ещё не собрано. Готовы рабочие документы: `README.md` и `PLAN.md`. Раздел «Запуск» будет заполнен после этапа 1 из `PLAN.md` командами, которые фактически сработали.

## Запуск

Пока нет.

## Главный сценарий

Проверяется на синтетических данных, например «Анна Тестова» и «Илья Примеров».

1. Открыть общую страницу.
2. Увидеть текущую дату и пять слотов: `09:00`, `11:00`, `13:00`, `15:00`, `17:00`.
3. Выбрать свободный слот, ввести ФИО и подтвердить запись.
4. Увидеть, что слот стал занятым и в нём отображается введённое ФИО.
5. Попробовать занять тот же слот другим ФИО и получить понятный отказ.
6. Обновить страницу или открыть приложение во втором браузере и увидеть ту же запись.

Дополнительно: отметить кормление синтетическим ФИО и увидеть обновлённую карточку «Последнее кормление».

## Границы

Входит:

* одна общая страница без регистрации и авторизации;
* пять фиксированных слотов только на текущую дату;
* запись в свободный слот по ФИО с защитой на сервере от повторной записи;
* SQLite как единственное хранилище состояния;
* карточка последнего кормления.

Не входит:

* авторизация, роли, личные кабинеты, справочник сотрудников;
* отмена и администрирование записей, уведомления, календарь на неделю, история действий;
* реальные ФИО, рабочие данные, секреты и внешние интеграции;
* деплой, масштабирование и production-grade надёжность.
